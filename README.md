# Cursor Website

A modern, responsive website built with vanilla HTML, CSS, and JavaScript.

## Structure

```
.
├── index.html    — Main HTML page
├── styles.css    — All styles (responsive, dark theme)
├── script.js     — Interactivity (navigation, animations, form)
└── README.md     — This file
```

## Features

- Dark-themed, modern design
- Fully responsive (desktop, tablet, mobile)
- Smooth scroll navigation
- Scroll-based reveal animations
- Mobile hamburger menu
- Contact form with visual feedback
- Decorative code editor visual
- No external dependencies (besides Google Fonts)

## Running Locally

Open `index.html` in any browser, or serve with a simple HTTP server:

```bash
# Python 3
python3 -m http.server 8000

# Node.js (npx)
npx serve .
```

Then visit `http://localhost:8000`.
